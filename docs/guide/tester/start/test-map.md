# What is tested where

This page maps each product area to the tests that cover it, so that a reviewer can find the tests for a change in seconds and see where there are none. Names are checked against the files by `scripts/docs-check.py`.

![Map of product areas to test coverage: the engine loop, bar aggregator, risk rules, paper broker, strategies, configuration parsing and the CLI guard are covered directly; the Alpaca and XTB adapters are covered through pure helpers and a fake session; live connectivity, reconnect and the kill switch end to end have no automated test.](../images/test-map.svg)

## Helpers

`tests/helpers.py`:

| Helper | Gives you |
|---|---|
| `T0` | `2026-10-21 14:30 UTC`, a fixed epoch for replay tests |
| `ticks(symbol, prices, step_sec=60, start=T0)` | one quote tick per price, spread 0.02 around it (mid equals the price) |
| `bars(symbol, closes, tf=M1, start=T0)` | flat bars, one per timeframe step, volume 0 |
| `wave(n)` | `100 + 10·sin(i/8)`: several SMA crossovers in 120 samples |
| `now_floor(step_sec=60)` | the wall clock floored to a bucket, for tests that must survive the calendar |

Fake transports live next to the tests that use them: `FakeSession` in `tests/test_xtb_broker.py` records every xAPI command; `Recorder` in `tests/test_engine_robustness.py` is a strategy that records the bars it receives.
